# Imagens do produto

As imagens publicadas neste diretório foram otimizadas a partir do arquivo `camisetapt.zip` enviado para esta implementação. Foram convertidas para WebP para reduzir o peso de transferência.

| Arquivo | Uso no site |
| --- | --- |
| `frente-principal.webp` | Foto principal frontal |
| `verso.webp` | Vista traseira |
| `modelo-masculino.webp` | Modelo masculino |
| `modelo-feminino.webp` | Modelo feminino |
| `close-estampa.webp` | Recorte individual da estampa; a faixa de montagem do original não foi utilizada |
| `detalhe-manga-costura.webp` | Recorte individual de manga e costura, sem chamadas promocionais do original |
| `lifestyle-externo.webp` | Foto editorial/lifestyle em ambiente externo |

O arquivo original que trazia alegações como composição do tecido, durabilidade e características de impressão **não é exibido como imagem completa**, pois essas informações ainda não foram confirmadas pelo responsável comercial. Atualize `app/config/product.ts` ao adicionar, remover ou substituir imagens.
