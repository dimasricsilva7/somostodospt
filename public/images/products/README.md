# Imagens do produto

As imagens publicadas neste diretório foram otimizadas a partir dos arquivos `camisetapt.zip` e `PT.zip` enviados pelo responsável. Foram convertidas para WebP para reduzir o peso de transferência, preservando proporções e sem substituir os originais.

| Arquivo | Uso no site |
| --- | --- |
| `frente-principal.webp` | Foto principal frontal |
| `verso.webp` | Vista traseira |
| `modelo-masculino.webp` | Modelo masculino |
| `modelo-feminino.webp` | Modelo feminino |
| `close-estampa.webp` | Recorte individual da estampa; a faixa de montagem do original não foi utilizada |
| `detalhe-manga-costura.webp` | Recorte individual de manga e costura, sem chamadas promocionais do original |
| `lifestyle-externo.webp` | Foto editorial/lifestyle em ambiente externo |
| `embalagem-ilustrativa.webp` | Imagem ilustrativa de apresentação da camiseta em caixa; não confirma que a embalagem física esteja incluída |
| `modelo-comicio-masculino.webp` | Imagem ilustrativa de modelo vestindo a camiseta em cenário de manifestação |
| `manifesto-vermelho.webp` | Imagem ilustrativa de multidão e bandeiras em composição de campanha |
| `modelo-comicio-feminino.webp` | Imagem ilustrativa de modelo vestindo a camiseta em cenário de comício |
| `multidao-brasilia.webp` | Imagem ilustrativa de grupo vestindo a camiseta em uma cena de campanha |

As cinco artes incluídas de `PT.zip` são identificadas como ilustrativas na galeria; elas não devem ser interpretadas como prova de embalagem incluída, evento real, estoque ou condição comercial. O arquivo original de outra remessa que trazia alegações técnicas não confirmadas não é exibido como imagem completa. Atualize `app/config/product.ts` ao adicionar, remover ou substituir imagens.
